## CodeCraft Infotech Quality Assurance Internship

### Task 1: Test Cases for a Simple Calculator Application

#### Objective
To create detailed test cases for a simple calculator application that performs addition, subtraction, multiplication, and division.

#### Scope
The test cases cover:

- Addition
- Subtraction
- Multiplication
- Division
- Zero values
- Negative numbers
- Decimal numbers
- Division by zero
- Blank inputs
- Non-numeric inputs
- Large numeric values
- Repeated calculations
- Reset/Clear functionality

#### Deliverable
The detailed test cases are available in:

**[test-cases.md](test-cases.md)**

#### Test Case Coverage
A total of 15 test cases have been created covering both valid and invalid inputs, along with error handling and boundary conditions.
